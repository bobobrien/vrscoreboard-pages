# VRScoreBoard — published board

`scores.json` is written automatically by the VRScoreBoard server (private repo
`bobobrien/VRScoreBoard`). Nothing else lives here. VRChat worlds poll it from
`https://bobobrien.github.io/vrscoreboard-pages/scores.json`, a host on VRChat's trusted
string-loading list, so players need no settings change to read the board.
